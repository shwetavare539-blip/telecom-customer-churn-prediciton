# Telecom Customer Churn Prediction

## Project Overview
This project predicts whether a telecom customer is likely to churn (leave the company) or stay using Machine Learning.

The model is trained on telecom customer data and deployed as an interactive Streamlit web application.

## Features
- Predict customer churn
- User-friendly Streamlit interface
- Real-time predictions
- Logistic Regression Machine Learning model

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Pickle

## Project Files
- app.py
- telecom_churn_model.pkl
- model_columns.pkl
- requirements.txt
